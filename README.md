## Student CRUD API

This project is a Student CRUD API developed using FastAPI.

## Features

- Create student
- Get all students
- Get student by ID
- Update student
- Delete student

## Technologies

- Python
- FastAPI
- Uvicorn

## How to Run

1. Install the requirements:

2. pip install -r requirements.txt

3. Run the application:

4. uvicorn main:app --reload

5. Open in browser:
http://127.0.0.1:8000/docs
